# Журнал четвёртого агента по металлам (mt4): 10 кругов «гипотеза → критерий заранее → цифры → вывод»

Задача: продолжить стратегии DCA с резервом для металлов. Основа — R3 (`found/metals.json`), R6 (агент 2), Q2 (агент 3,
`found/metals-agent3-best.json`). Новое: пересчёт на пузыре 2025–26, **дневная модель** (как крипто-приложение: ежедневный взнос,
решение по вчерашнему закрытию), новые сигналы (крипта, доллар, реальная ставка, VIX, серебро/золото, «пузырь и сдувание», фитили),
простой резерва, связь режимов металлов и крипты. Стенд — `app/mt4_lib.py` (новый файл; чужие стенды не меняются), логи —
`scratchpad/mt4/rN.txt`.

## Протокол (записан до первого круга)

**Месячная модель** — протокол агента 3 без изменений: $300/мес., решение по месяцу, исполнение по средней следующего месяца, комиссия 0,1%.
Отбор — 8 металлов, 1982–98 (`sel_ok`: не хуже −0,5 п.п. на ≥ 7/8, худший ≥ −3%, сумма лог-разниц ≥ +4, сдвиг на месяц ≥ 0,
старты 1982–90 не хуже в ≥ 70%, плато). Вето — 1999–2026 против R3 (медиана ≥ 0, не хуже ≥ 5/8, худший ≥ −10%) только для выбранного.
Экзамен — палладий, олово, только в итоге. Данные — замороженные `cache/metals_agent2_data.pkl` (месяцы по 2026-10) + ноябрь 2026
(неполный, средняя дневных фьючерсов, приведённая к ряду Всемирного банка по октябрю) только для пересчёта «что сейчас».

**Дневная модель** (данные короче — свой протокол):
- Ряды: дневные закрытия Yahoo (фьючерсы, непрерывный ближний контракт). **Отбор — 4 металла:** золото GC=F, серебро SI=F, платина PL=F,
  медь HG=F, общий период 2000-09-01 … 2026-11-23. **Экзамен:** палладий PA=F (1998–), алюминий ALI=F (2014–) — только в итоге.
  Олова в дневных данных Yahoo нет.
- Модель: взнос $10 в каждый торговый день; план дня (1 — взнос; 0 — взнос в резерв; 1 + g — взнос и доля g резерва; −f — продать долю f)
  решается по закрытию дня j и исполняется по закрытию дня j + 1 (сдвиг 0) или j + 2 (сдвиг 1); комиссия 0,1%; итог — к дневному DCA, %.
- **Половины:** H1 = 2000-09 … 2013-09, H2 = 2013-10 … 2026-11, каждая со старта с нуля. Ячейка = металл × половина (8 ячеек).
- **Критерий отбора правила (против текущей основы):** не хуже (−0,5 п.п.) в ≥ 7 из 8 ячеек, худшая ячейка ≥ −3%, сумма лог-разниц по 8 ячейкам ≥ +4,
  **каждая половина** (сумма по 4 металлам) ≥ 0; сдвиг исполнения на 1 день — сумма ≥ 0; **плато** (соседи ±1 шаг по каждой оси тоже проходят);
  **без одного эпизода** — правило «выключено» (план = план основы) в окне эпизода, и сумма по 8 ячейкам остаётся ≥ 0 для каждого из
  эпизодов 2008-07…2009-03, 2011-04…2013-12, 2020-02…2020-04, 2022-03…2022-10, 2025-06…2026-11; **старты** каждый январь 2001–2020 до конца —
  не хуже в ≥ 70%. Сложность — только за прибавку; при близких суммах (±2) — проще.
- Предупреждение: дневные ряды начинаются в 2000 — весь период лежит в «суперцикле» (после 1999), отбора «без суперцикла» здесь нет;
  поэтому для правил, переносимых из месячной модели, сначала смотрю месячную проверку агента 3 (1982–98 → вето), а дневная модель — вторая проверка.
- **Маржа** для итогового кандидата: заём 0,5× суммы докупки из резерва при ставке ФРС < 3% (ставка + 2% годовых), ликвидация при обеспечении ≤ 1,1
  по дневным минимумам со стрессом ×1/×0,8/×0,7; прогоны — половины, весь период, старты 2001–2020, сдвиг 0/1. Требование — 0 ликвидаций.

## Круг 1. R3 / R6 / Q2 в пузыре 2025–26 и сейчас: `app/mt4_r1.py`

**Гипотеза (записана до запуска).** H1a: на подъёме 2025 – январь 2026 все три версии продавали драгметаллы (перегрев «цена ×1,81 к средней
за 3 года и +86% за год» у серебра и платины, маркеры вершины), и продажи пришлись на цены не ниже 75% от максимума. H1b: после падения
(золото −31%, серебро −63% от рекорда в дневных ценах) серии докупок нет — макро-маркеры дна (доллар, ставка, кривая, безработица) не горят,
резерв простаивает; это и есть «ошибка сейчас». H1c: на окне «старт 2024-01 → 2026-11» версии не хуже DCA на золоте, серебре, платине, палладии, меди.
**Критерий (заранее).** H1a подтверждена, если у серебра и платины каждая версия продала суммарно ≥ 30% позиции в месяцы с ценой ≥ 75% от максимума
2025–26 (месячного); H1b — если в 2026-02 … 2026-10 ни у одного из 5 металлов нет месяца с докупкой резерва; H1c — если итог к DCA ≥ −0,5% на ≥ 4 из 5.

**Цифры** (лог — `scratchpad/mt4/r1.txt`; месячные средние, ноябрь 2026 неполный; максимум месячный, дневной рекорд золота 5318 — 29.01.2026):

|---|---|---|---|---|---|
| золото | 5020 (02.2026) → 3885 (−23%) | 15 / 20 / 15% (одна продажа 05.2026) | 16% | +1,3 / +1,7 / +1,3 | +25,0 → +26,6 |
| серебро | 92,1 (01.2026) → 48,6 (−47%) | **67 / 95 / 95%** (12.2025 … 05.2026) | **99%** | **+46 / +61 / +62** | +122 → **+264** |
| платина | 2434 (01.2026) → 1463 (−40%) | 36 / 63 / 60% | 78% | +16 / +24 / +26 | +54 → +94 |
| палладий | 1874 (01.2026) → 977 (−48%) | 0 / 0 / 0% (продажа 15% только в 05.2026 по 1445) | 68% | +4,4 | +118 → +192 |
| медь | 14508 (10.2026, рекорд) → 13448 | 15% (05.2026) | 15% | +0,1 | +147 → +146 |

- Как это было: серебро — перегрев «цена ×1,81 к средней за 3 года и +86% за год» с 12.2025; затяжной перегрев (R6/Q2) с 01.2026 продавал по 50% в месяц
  до 05.2026 — продано 95% позиции по 66–92 при вершине 92 (дневной рекорд 115). Платина — то же в 01–02.2026. Золото до перегрева не дошло
  (рост за год ≤ +86%, цена к средней за 3 года < 1,81), маркеры вершины дали лишь одну продажу 15% в 05.2026 (макро-вершина: нефть, инфляция, ставка) —
  у всех металлов сразу. Остывание Q2 с 06.2026 копит все взносы серебра и платины в резерв.
- Сейчас (решение по 2026-10): маркеров дна **0 из 8 у всех 10 металлов**, вершины золото 3/8, серебро 3/8, платина 1/7, медь 4/8, олово 4/8.
  Ни одной докупки резерва с 01.2026. У серебра в резерве 99% капитала, у платины 78%, палладия 68%, никеля 87%, олова 83%.
- Пузырь сильно поднял итог там, где продали (серебро Q2 к DCA после 1999: +122 → +264, платина +54 → +94), и ничего не дал золоту (+25 → +27)
  и палладию (рост итога — только из-за падения цены при старом резерве).

**Вывод.** H1a **подтверждена** (серебро и платина: продано 36–95% в верхней зоне; R6/Q2 — лучшие), H1b **подтверждена** (докупок нет, резерв простаивает),
H1c **подтверждена** (5/5 не хуже DCA с 2024-01). Ошибки сейчас: (1) золото — пузырь пропущен почти целиком (−15% в мае, после вершины),
и палладий — без продаж у вершины; (2) серебро и платина — почти весь капитал в деньгах при цене −40…−60% от вершины; дна по макро нет,
и правило «ждать макро-дно» после пузыря может держать деньги годами (после 2011 — до 2015–16). Это хорошо, если повторится 2011–15,
и плохо при V-образном восстановлении. Дальше: дневная модель и «пузырь/сдувание» по цене (круги 2–3), простой резерва (круг 7).

## Круг 2. Дневная модель: месячные макро-сигналы Q2 в ежедневном исполнении: `app/mt4_r2.py`

**Гипотеза (записана до запуска).** H2a: месячный план Q2 (решение по месяцу M, известно в его конце), исполненный ежедневно в месяце M+1
(продажа f и докупка g «размазаны» по торговым дням: в день 1 − (1 − f)^(1/nd)), даёт к дневному DCA почти то же, что месячная модель на том же
отрезке (2000-09 … 2026-11; разница медианы по 4 металлам отбора ≤ 5 п.п.), и остаётся в плюсе в обеих половинах (H1 2000-09…2013-09, H2 2013-10…2026-11).
H2b: исполнение всего объёма в первый торговый день месяца не лучше размазанного (сумма лог-разниц ≤ +2) — размазывание проще для перпов/спота.
**Критерий (заранее).** H2a подтверждена, если Q2-дневная к дневному DCA: сумма по 8 ячейкам > 0, каждая половина ≥ 0, сдвиг на день ≥ 0,
и |медиана (дневная − месячная)| ≤ 5 п.п.; H2b — если «первый день» к «размазанному» по 8 ячейкам в пределах ±2 или хуже.
Q2-дневная (размазанная) становится основой дневной модели, если H2a подтверждена; иначе основа — дневной DCA.

**Цифры** (лог — `scratchpad/mt4/r2.txt`, `r2b.txt`; итог к дневному DCA, % H1 / H2 / весь отрезок 2000-09 … 2026-11-23):

| металл | R3 дневная | R6 дневная | **Q2 дневная** | Q2 месячная (тот же отрезок) |
|---|---|---|---|---|
| золото | +13,8 / +2,4 / +26 | +14,0 / +3,1 / +27 | +13,9 / +2,4 / +27 | +12,0 / +0,4 / +24 |
| серебро | +102 / +53 / +245 | +109 / +73 / +306 | +101 / +72 / +291 | +93 / +32 / +199 |
| платина | +73 / +16 / +68 | +69 / +27 / +81 | +73 / +27 / +83 | +80 / +8 / +68 |
| медь | +129 / +2 / +138 | +127 / +2 / +136 | +129 / +2 / +140 | +127 / −1 / +129 |
| палладий (экз.) | +39 / +57 / +155 | +41 / +69 / +183 | +39 / +58 / +156 | +55 / +40 / +143 |
| алюминий (экз., с 2014) | — / +7 | — / +7 | — / +7 | — / +3 |

- Q2 дневная к дневному DCA: сумма **+303** (H1 +221, H2 +82), 8/8, сдвиг на день +302, без любого эпизода ≥ +210, старты 100%.
- Дневная − месячная Q2 на одинаковом конце: 2025-12 — медиана **−0,9 п.п.** (золото +0,2, серебро −2, платина −12, медь +5);
  2026-10 — +4,7 п.п. (разница — в цене конца: закрытие 30.10 против средней октября). На конце 23.11 медиана +13 — серебро упало ещё на 25%
  после октябрьской средней, а у Q2 99% денег в резерве.
- «Всё в первый день месяца» к размазанному: Q2 +0,6 (6/8, медь H1 −6,7), R3 −5,4, R6 −1,9 — не лучше.
- Q2 к R3 в дневной модели: +20,7 (H1 −0,1, H2 +20,8: серебро +13, платина +9 — пузырь 2026), R6 к R3 +23,2 (платина H1 −2,3).
- Важное наблюдение: во второй половине (2013–26) у золота и меди Q2 почти не отличается от DCA (+2,4 и +1,8): весь выигрыш H2 — серебро и платина в 2026.

**Вывод.** H2a **подтверждена** (на одинаковом конце дневная ≈ месячная, обе половины в плюсе), H2b **подтверждена** (первый день не лучше).
Основа дневной модели — **Q2д = месячный план Q2, исполняемый ежедневно равными долями в следующем месяце**. Это и есть способ
торговать месячные сигналы в приложении: план месяца известен в его первый день, дальше ежедневные взносы/продажи равными долями.

## Круг 3. «Пузырь и сдувание» по дневной цене (поверх Q2д): `app/mt4_r3.py`

**Гипотеза (записана до запуска).** Золото в 2025–26 пропустило пузырь: макро-перегрев (×1,81 к средней за 3 года и +86% за год) у золота не срабатывает
никогда, а дневная цена далеко ушла от 200-дневной средней. H3a «пузырь»: цена / SMA200 > X (1,20/1,25/1,30/1,35/1,40) И рост за 250 дней > Y (30/50/70%) →
продать s (10/20/30%) позиции, не чаще раза в 21 торговый день, пока условие держится (если план Q2д в этот день продаёт меньше).
H3b «сдувание» (поверх лучшего H3a, если он принят, иначе поверх Q2д): в 500 дней после продажи по H3a, если цена < SMA200 × (1 − z) (z = 0/10/20%), —
докупать резерв g (25/50% в месяц, равными долями по дням).
**Критерий (заранее).** Дневной протокол против Q2д (8 ячеек, половины, сдвиг, без эпизода, старты) + плато по (X, Y, s) / (z, g).
Для принятого — месячный аналог (цена / средняя 10 мес. > X и рост за 12 мес. > Y → продать s) по протоколу агента 3 (отбор 1982–98, вето после 1999) — как справка.

**Цифры** (лог — `scratchpad/mt4/r3.txt`). Диагностика (максимум цены / SMA200 и роста за 250 дней): золото 2006 1,39/+68%, 2011 1,28/+52%,
**2025–26 1,41/+89%** (максимум за 26 лет); серебро 2011 1,75/+173%, 2025–26 2,47/+275%; платина 2025–26 1,92/+201%; медь 2006 1,84/+178%.
- H3a: **0 из 45** вариантов не проходят даже базовые условия: сумма от −14 (X 1,40, Y 70%, s 10%) до −368; лучший — 5/8, серебро −4,9/−8,0, медь −7,7 в H1.
  Выигрывает только золото во второй половине (+4…+21 — это один эпизод 2025–26), проигрывают серебро (2006, 2010–11 — продажи в начале многолетнего роста)
  и медь (2005–06).
- H3b (сдувание, поверх Q2д с меткой пузыря X 1,30 / Y 50%): 0 из 6; лучший z 20% / g 50% — сумма −1,1 (медь H1 +19, серебро −8/−9 — после 2011 серебро
  падало ещё 4 года, ранние докупки «ниже SMA200» тратили резерв задолго до дна).

**Вывод.** **Отвергнута** (обе части). Дневные ценовые «пузыри» повторяют урок агента 3: на суперцикле продажа по скорости роста — это продажа в начале
многолетних подъёмов (серебро 2006/2010, медь 2005–06). Золото 2025–26 — единственный эпизод, где правило помогло бы; подгонять под него правило нельзя.
Месячный аналог не проверялся: он совпадает с «параболой» и «тёплой ступенью» агента 3, уже отвергнутыми вето.

## Круг 4. Крипта как ведущий индикатор металлов: `app/mt4_r4.py`

**Гипотеза (записана до запуска).** По `au_journal.md`: после стресса BTC (−25% за 30 дней) золото следующие 90 дней хуже обычного на ~3%, после эйфории/рекорда BTC — лучше.
H4a (диагностика): эффект есть у всех 4 металлов отбора и в обеих половинах эры BTC (2014-10…2020-09 / 2020-10…2026-11).
H4b «пауза после стресса»: если за последние W дней (30/60/90) был день, когда BTC за 30 дней упал на ≥ T (20/25/30%), — ежедневный взнос металла
не покупается, а откладывается в отдельный «долг» (не смешивается с резервом Q2д) и покупается целиком в первый день после окна.
H4c «не продавать в эйфорию крипты»: если BTC обновлял рекорд за последние E дней (30/60/90), продажи Q2д откладываются (план дня = обычный взнос).
**Критерий (заранее).** Дневной протокол против Q2д + обе половины эры BTC (сумма по 4 металлам ≥ 0 в каждой) + плато по (T, W) / E.
Диагностика — «сигнал», если избыток 90 дней одного знака у ≥ 3 из 4 металлов и в обеих половинах эры BTC.

**Цифры** (лог — `scratchpad/mt4/r4.txt`; события не чаще раза в 30 дней; избыток 90 торговых дней к среднему эры BTC, % [половины эры]):

| событие BTC | золото | серебро | платина | медь | палладий | алюминий |
|---|---|---|---|---|---|---|
| −25% за 30 дн. (14 событий) | −6,7 [−3,0/−10,3] | −9,1 [−1,1/−17,2] | −6,8 [−2,6/−11,1] | −4,7 [−2,2/−7,3] | −4,1 | −1,5 |
| −20% за 30 дн. (25) | −2,8 [−0,9/−4,8] | −6,3 | −6,1 | −4,4 | −1,4 | −1,6 |
| рекорд BTC (20) | +3,6 [+1,0/+6,0] | +4,6 [−1,0/+10,1] | +3,9 | +3,3 | +6,5 | +5,1 |
| +50% за 30 дн. (15) | −0,7 | −1,8 | +0,7 | +3,9 | +5,1 | +6,2 |

- H4b (пауза взносов после стресса): все 9 вариантов в пределах −1,1…+2,9 (лучший T 25%, W 60: 8/8, эра BTC +4,1/+1,8, но сумма +2,9 < +4).
  Отложить взносы на 2 месяца — значит купить на 3–6% дешевле лишь ~1/6 годовых взносов: эффект мал по построению.
- H4c (не продавать в эйфорию): E 30 — ровно 0 (продажи не совпадали с рекордами), E 60 — +11,8, E 90 — +9,2 (эра BTC +0,0/−1,0).
  Весь выигрыш — пропуск продаж серебра и платины в 06–07.2021 (после рекорда BTC 04.2021) — один эпизод, плато нет.

**Вывод.** H4a **подтверждена**: стресс BTC — отрицательный 90-дневный фон для всех металлов в обеих половинах эры BTC (сильнее во второй);
рекорд BTC — положительный (3/4 в первой половине, 4/4 во второй). Но как **правила** H4b и H4c **отвергнуты**: пауза взносов слишком мала
для DCA (+2,9 < +4), а «не продавать в эйфорию» держится на одном эпизоде 2021. Практический смысл: стресс BTC — повод не торопиться

## Круг 6. Серебро/золото как индикатор ликвидности и «дешёвое серебро»: `app/mt4_r6.py`

**Гипотеза (записана до запуска).** H6a (диагностика, из `au_journal`: «серебро хуже золота = вынос ликвидности»): серебро за 21 торговый день
отстало от золота на ≥ 10% → все металлы следующие 63 дня хуже обычного (знак у ≥ 3 из 4, обе половины).
H6b «дешёвое серебро»: золото/серебро ≥ R (70/75/80/85/90) → серебро покупает резерв g (25/50% в месяц), даже вне макро-серии и в остывании Q2.
Классическое правило; эпизоды отношения > 80 — 1990–93, 2003, 2008–09, 2016, 2018–20, 2025-04. Честно: я знаю, что сейчас отношение ≈ 85,
и что это правило сейчас велит покупать серебро — поэтому проверяю строже: **сначала месячная модель по протоколу агента 3** (отбор 1982–98:
серебро не хуже Q2 и сумма по 8 металлам ≥ +4 не требуется — правило меняет один металл; требую серебро 1982–98 ≥ +2%, сдвиг на месяц ≥ 0,
старты 1982–90 не хуже в ≥ 70%, плато по R и g; вето после 1999 — серебро не хуже R3 и Q2), **затем дневная** (серебро: обе половины ≥ 0,
сдвиг ≥ 0, без любого эпизода ≥ 0, старты ≥ 70%, плато). H6c — то же для платины по отношению платина/золото ≤ P (0,45/0,5/0,55/0,6) — как контроль
(если «дешёвый к золоту» — общий принцип, должно работать и там).

**Цифры** (лог — `scratchpad/mt4/r6.txt`).
- H6a: отставание серебра от золота ≥ 5% за 21 день → 63 дня: золото −0,7 [+0,1/−1,9], серебро −0,3 [+2,1/−3,3], платина −1,5, медь −0,4, палладий −3,1;
  ≥ 10% и ≥ 15% — знаки меняются между половинами (медь −8,1/+4,7; серебро −1,8/+20,5). Устойчивого «выноса ликвидности» нет.
- H6b, **месячная модель, отбор 1982–98** (серебро к Q2): R 70/75 → −7…−16 (в 1990–96 отношение 75–98 держалось шесть лет, серебро стояло на $4–5,5,
  и резерв уходил задолго до конца боковика); R 80 → −1,0/−2,3; R 85 → −0,1/−0,7; R 90 → +0,6/+0,3. **Ни один не прошёл** (порог +2%).
  Справочно (после решения) 1999–2026 к Q2: +6…+17% у всех 10 вариантов (R 80–85: +16…+17).
- H6b, **дневная модель** (серебро к Q2д): R 80/85/90 при g 25/50% — **все 6 проходят с плато**: H1 0…+1,1, H2 +8…+11, сдвиг ≥ +8, без любого эпизода ≥ +5,7,
  старты 100%. Выигрыш — 2016 и 2018–20 (резерв от продаж 2011 простаивал; отношение 80–120 при серебре $12–17).
- H6c (контроль, платина/золото ≤ P): месячная 1982–98 — ровно 0 (отношение никогда не было ниже 0,6), после 1999 +3…+9; дневная H2 −8…−16
  (докупала платину в 2026 после продаж и падения), без эпизода 2025–26 — +9…+11. Отклонено.

**Вывод.** H6a **отвергнута**. H6b **частично подтверждена**: «дешёвое серебро» (золото/серебро ≥ 80–90) работает в дневной модели 2000–26 и после 1999 в месячной,
но **не проходит отбор 1982–98** (там высокое отношение было признаком долгого боковика, а не дна) — по протоколу в основу не берётся.
Это лучший пока способ вернуть простаивающий резерв серебра в рынок; оставляю его кандидатом «опции» и проверю вместе с кругом 7.
H6c **отвергнута** — «дешёв к золоту» не общий принцип.

## Круг 7. Простой резерва: доход векселей и медленный возврат резерва по тренду: `app/mt4_r7.py`

**Гипотеза (записана до запуска).** У Q2 резерв после продаж годами лежит без дела (золото: продано в 2011, затем 2013–2026 — рост ×3 без докупок;
серебро сейчас — 99% капитала в деньгах). H7a: доход 3-месячных векселей на резерв (как у USDC/T-bill) — всегда плюс; меряю величину.
H7b «медленный возврат по тренду»: если с последней продажи прошло ≥ Y месяцев (24/36/48), нет серии и продаж, и цена выше средней за 10 месяцев
(восходящий тренд), — докупать r (5/10/20%) резерва в месяц. H7c — то же без фильтра тренда.
**Критерий (заранее).** Месячная модель — протокол агента 3 (отбор 1982–98 `sel_ok` против Q2 + плато по (Y, r), вето 1999–2026 против R3 для выбранного);
затем дневная (протокол против Q2д). Для H7a — только величина (не правило торговли). Если H7b/H7c не пройдут — проверить «дешёвое серебро»
круга 6 как частный случай возврата резерва не нужно (уже сделано).

**Цифры** (лог — `scratchpad/mt4/r7.txt`).
- Сначала факт о «простое»: у Q2 золото продавало только в 2007–08, 2010 и 2011 (резерв 91% в 2013–15), докупило всё в серии 07–12.2015
  (1076–1159) и **с 2016 года резерва нет (≈1%) и нет ни одного действия до 05.2026** — это не простой денег, а простой правил: 10 лет чистого DCA.
  Простой денег — у серебра 2013–15 (99%) и сейчас (99%), у платины 2013–15 и 2023–26 (28–46%).
- H7a (доход векселей на резерв): месячная 1982–98 / 1999–2026 — золото +11 → +29 / +26 → +27, серебро +26 → +45 / +211 → +227, платина +24 → +45 / +80 → +91,

**Вывод.** H7a **подтверждена** как способ реализации: резерв должен лежать в векселях / доходном долларе (+1…+20% к итогу по металлам; это не правило торговли,
а то, где держать деньги). H7b и H7c **отвергнуты**: на боковике 1982–98 возврат резерва без макро-дна вреден (то же, что у агента 2, круг 2), а в дневной модели
плюс держится на одном цикле 2021 → 2025. «Простой» золота после 2016 — следствие того, что макро-маркеры вершины и дна у золота почти не горят;

## Круг 8. Ловушка для фитилей на металлах: `app/mt4_r8.py`

**Гипотеза (записана до запуска).** На металлах внутридневные провалы редки (фьючерсы, ликвидный рынок), поэтому лимитные заявки ниже вчерашнего закрытия
почти не исполняются и дают мало. H8a (частота): провал минимума дня ≥ 3% ниже вчерашнего закрытия — у золота < 5 раз в год, ≥ 5% — < 1 раза в год;
у серебра/платины/меди чаще в 2–4 раза. H8b (правило): каждый день лимит на покупку по цене вчерашнего закрытия × (1 − k) (k = 3/5/8%) на долю f (10/20/30%)
резерва Q2д; заявка живёт день. Свечи (минимумы) есть с 2009 года, поэтому половины для H8b — 2009–2017 / 2018–2026-11.
**Критерий (заранее).** H8a — подтверждена, если частоты в пределах заявленного. H8b — против Q2д на 4 металлах: сумма по 8 ячейкам (металл × половина) ≥ +2
(сниженный порог: правило без риска, только перенос момента покупки), каждая половина ≥ 0, не хуже 7/8, плато по (k, f).
Дополнительно — проверка качества минимумов (у непрерывного ряда фьючерсов бывают ложные минимумы на ролловерах): отдельно считаю долю «фитилей», после которых
закрытие дня выше уровня заявки (настоящий фитиль), и долю дней с минимумом ниже 0,8 × закрытия (ошибки данных).

**Главные уроки.**

3. Фоны крипты и акций (стресс BTC, доллар, VIX) у металлов слабее и менее устойчивы, чем у крипты; стресс BTC — единственный устойчивый фон (минус для металлов на 90 дней).
