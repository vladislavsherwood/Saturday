# Журнал четвёртого агента по металлам (mt4): 10 кругов «гипотеза → критерий заранее → цифры → вывод»

Задача: продолжить стратегии DCA с резервом для металлов. Основа — R3 (`found/metals.json`), R6 (агент 2), Q2 (агент 3,
`found/metals-agent3-best.json`). Новое: пересчёт на пузыре 2025–26, **дневная модель** (как крипто-приложение: ежедневный взнос,
решение по вчерашнему закрытию), новые сигналы (крипта, доллар, реальная ставка, VIX, серебро/золото, «пузырь и сдувание», фитили),
простой резерва, связь режимов металлов и крипты. Стенд — `app/mt4_lib.py` (новый файл; чужие стенды не меняются), логи —
`scratchpad/mt4/rN.txt`.

## Протокол (записан до первого круга)

**Месячная модель** — протокол агента 3 без изменений: $300/мес., решение по месяцу, исполнение по средней следующего месяца, комиссия 0,1%.
Отбор — 8 металлов, 1982–98 (`sel_ok`: не хуже −0,5 п.п. на ≥ 7/8, худший ≥ −3%, сумма лог-разниц ≥ +4, сдвиг на месяц ≥ 0,
старты 1982–90 не хуже в ≥ 70%, плато). Вето — 1999–2026 против R3 (медиана ≥ 0, не хуже ≥ 5/8, худший ≥ −10%) только для выбранного.
Экзамен — палладий, олово, только в итоге. Данные — замороженные `cache/metals_agent2_data.pkl` (месяцы по 2026-10) + ноябрь 2026
(неполный, средняя дневных фьючерсов, приведённая к ряду Всемирного банка по октябрю) только для пересчёта «что сейчас».

**Дневная модель** (данные короче — свой протокол):
- Ряды: дневные закрытия Yahoo (фьючерсы, непрерывный ближний контракт). **Отбор — 4 металла:** золото GC=F, серебро SI=F, платина PL=F,
  медь HG=F, общий период 2000-09-01 … 2026-11-23. **Экзамен:** палладий PA=F (1998–), алюминий ALI=F (2014–) — только в итоге.
  Олова в дневных данных Yahoo нет.
- Модель: взнос $10 в каждый торговый день; план дня (1 — взнос; 0 — взнос в резерв; 1 + g — взнос и доля g резерва; −f — продать долю f)
  решается по закрытию дня j и исполняется по закрытию дня j + 1 (сдвиг 0) или j + 2 (сдвиг 1); комиссия 0,1%; итог — к дневному DCA, %.
- **Половины:** H1 = 2000-09 … 2013-09, H2 = 2013-10 … 2026-11, каждая со старта с нуля. Ячейка = металл × половина (8 ячеек).
- **Критерий отбора правила (против текущей основы):** не хуже (−0,5 п.п.) в ≥ 7 из 8 ячеек, худшая ячейка ≥ −3%, сумма лог-разниц по 8 ячейкам ≥ +4,
  **каждая половина** (сумма по 4 металлам) ≥ 0; сдвиг исполнения на 1 день — сумма ≥ 0; **плато** (соседи ±1 шаг по каждой оси тоже проходят);
  **без одного эпизода** — правило «выключено» (план = план основы) в окне эпизода, и сумма по 8 ячейкам остаётся ≥ 0 для каждого из
  эпизодов 2008-07…2009-03, 2011-04…2013-12, 2020-02…2020-04, 2022-03…2022-10, 2025-06…2026-11; **старты** каждый январь 2001–2020 до конца —
  не хуже в ≥ 70%. Сложность — только за прибавку; при близких суммах (±2) — проще.
- Предупреждение: дневные ряды начинаются в 2000 — весь период лежит в «суперцикле» (после 1999), отбора «без суперцикла» здесь нет;
  поэтому для правил, переносимых из месячной модели, сначала смотрю месячную проверку агента 3 (1982–98 → вето), а дневная модель — вторая проверка.
- **Маржа** для итогового кандидата: заём 0,5× суммы докупки из резерва при ставке ФРС < 3% (ставка + 2% годовых), ликвидация при обеспечении ≤ 1,1
  по дневным минимумам со стрессом ×1/×0,8/×0,7; прогоны — половины, весь период, старты 2001–2020, сдвиг 0/1. Требование — 0 ликвидаций.

## Круг 1. R3 / R6 / Q2 в пузыре 2025–26 и сейчас: `app/mt4_r1.py`

**Гипотеза (записана до запуска).** H1a: на подъёме 2025 – январь 2026 все три версии продавали драгметаллы (перегрев «цена ×1,81 к средней
за 3 года и +86% за год» у серебра и платины, маркеры вершины), и продажи пришлись на цены не ниже 75% от максимума. H1b: после падения
(золото −31%, серебро −63% от рекорда в дневных ценах) серии докупок нет — макро-маркеры дна (доллар, ставка, кривая, безработица) не горят,
резерв простаивает; это и есть «ошибка сейчас». H1c: на окне «старт 2024-01 → 2026-11» версии не хуже DCA на золоте, серебре, платине, палладии, меди.
**Критерий (заранее).** H1a подтверждена, если у серебра и платины каждая версия продала суммарно ≥ 30% позиции в месяцы с ценой ≥ 75% от максимума
2025–26 (месячного); H1b — если в 2026-02 … 2026-10 ни у одного из 5 металлов нет месяца с докупкой резерва; H1c — если итог к DCA ≥ −0,5% на ≥ 4 из 5.
