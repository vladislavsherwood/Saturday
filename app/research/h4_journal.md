Основа — combo4 (57 правил, `found/combo4-best.json`) + отложенная паника `Boost(2, { k: 0, A: 0 })` + «ловушка для фитилей» (`found/wick-best.json`):
отбор 5273 / 17 / 33 / −0,6, экзамен 2319 / 14 / 28 / 26,3, 50 случ. 935 / 48 / 95 / −63,6, 100 новых 525 / 92 / 183 (к combo4 без фитилей: +0,946, 100н +0,277, 74/19).
Дополнительно проверяю на combo4 без фитилей (`P.setBaseline(S57, L.pol0)`).
Инструменты: `h4_lib.js` (основа, годовая разбивка, обёртка политики с воротами/бюджетом паники), `h4_diag.js`, `h4_month.js`, `h4_dec.js`, `h4_attr.js`, `h4_feat.js`, `h4_tl.js`
(диагностика), `h4_r*.js` (круги). Логи — `scratchpad/h4/`.

**Критерий (заранее, до тестов).** Кандидат принимается, только если:
1. доход (Σ лог-медиан отбор + экзамен + 50 случ. к основе combo4 + фитили) > 0 и строгая проверка ✔ на всей выборке и в каждом сегменте (крупные / альты / мемы);
2. 100 новых: средний лог к основе > 0 и «лучше/хуже» в плюс (лучше > хуже);
3. плато: соседние параметры тоже в плюсе (и в большинстве ✔);
4. обе половины истории монет не хуже (строгая проверка это включает: монет/половин в плюсе, худшая половина);
5. нельзя чинить 2019 ценой 2020 (паника 2019 окупается в 2020): смотрю изменение прироста по годам, 2020 не должен проседать заметнее выигрыша 2019;
6. то же на основе combo4 без фитилей — не хуже (знак дохода и строгая);
7. сложность оправдана только прибавкой: при равенстве — проще. Отвергнутое записываю.

## Диагностика (81 монета = отбор + экзамен + 50 случ.; отдельно 100 новых; сдвиг 0)

Скрипты: `h4_diag.js` (деньги по семьям и дни по правилам за год), `h4_month.js` (помесячно), `h4_dec.js` (разложение года), `h4_attr.js` («цена» сделок года),
`h4_feat.js` (признаки покупок и их исход), `h4_tl.js` (хронология монеты). Логи `diag_w.log`, `month_w.log`, `dec.log`, `attr.log`, `feat.log`.

**Главное: годовой прирост ln(капитал/DCA) смешивает действия года с «наследством».** Раскладываю: B1 — пассивный двойник (состояние на начало года держать без сделок,
взносы года покупать как DCA); «действия года» = ln(V_конец / B1_конец), «наследство» = остальное. Если стратегия впереди DCA (ln > 0) и почти вся в монете,
одинаковые взносы тянут отношение к 1 — прирост года отрицателен без единой плохой сделки («разбавление»). Медианы по монетам (combo4 + фитили):

**Риски и ограничения.** (1) Кандидат держится на одном событии; 100 новых не независимы по времени (те же 02–03.2019, задеты 10 монет). (2) Пересекается с «дырой 1» `gap_journal.md`
(дно цикла в хроническом медвежьем рынке, 12.2018 / 06.2022) — её закрывает агент h2 (`h2_lib.js`): оба правила тратят один и тот же резерв в 12.2018–03.2019;
если кандидат h2 покупает на дне, прибавка h4 почти наверняка исчезнет — проверять только вместе. (3) Ложный отскок (как 12.2018) стоит мало
(−0,013), но покупки потом могут быть проданы на страхе дешевле. (4) Нужны индикаторы `btcup90` (BTC к минимуму закрытий BTC за 90 дней − 1, %) и `btc200` (BTC к своей 200-дн. средней) —
в приложении/движке их нет; `btcath` есть. (5) Маржа не проверялась (правило тратит только свой резерв, без плеча). (6) Годовые приросты ln(V/DCA) — плохая мера «провальных лет»:
судить по действиям года (`h4_dec.js`).
