# Журнал агента улучшения №9 (imp9): хедж вместо продажи и шорт BTC

Основа: `app/found/combo-best.json` (F + C1.25 + C6) и `combo-best-margin.json` (R16 + A4 ×1,4 + шорт BTC 20%); `combo2-best.json` на старте нет.
Инструменты: `app/imp9_export.py` (цена/максимум BTC по дням и дневной фандинг монет из `agent3-coin-funding.json` → scratchpad/imp9_aux.json),
`app/imp9_sim.js` (копия edge() из agent_sim.js с режимами хеджа и ликвидацией по правилам Hyperliquid).

Правила Hyperliquid в модели хеджа: залог перпов — только USDC (резерв монеты) + нереализованный PnL перпов, спотовые монеты не считаются;
ликвидация, когда стоимость счёта перпов ≤ поддерживающей маржи (BTC 1,25%, ETH 2%, остальные 5% номинала) по максимуму дня;
стресс — максимумы дня ×1,2/×1,3. Фандинг — исторический дневной ряд монеты (с 2020 г.; шорт получает при f > 0), до начала ряда 0;
комиссия перпа 0,045% (спот в модели 0,1%).

## Круг 1. Хедж вместо продажи по монетам

**Гипотеза (заранее).** Если вместо каждой продажи (доля f открытой позиции) открывать шорт перпа той же монеты (или BTC) на ту же сумму,
сохраняя спот, и закрывать весь хедж на первом сигнале покупки, то по монетам (отбор 17, экзамен 14, 50 случайных; худший из двух сдвигов)
итог не хуже основы по строгой проверке, доход ≥ основы, 0 ликвидаций по правилам Hyperliquid (в т.ч. максимумы +20/+30%).
Ожидание: фандинг в жадности платит шортам — плюс; выкуп всего хеджа на первом сигнале покупки вместо долей резерва — неизвестно.

**Проверка.** `app/imp9_loop1.js`; режимы own (свой перп), btc (шорт BTC), mix (свой перп, если есть ряд фандинга, иначе BTC);
ограничение залога cov: хедж не больше, чем «USDC резерва ≥ cov × номинал всего хеджа», остальное продаётся как обычно.
Режим sell совпадает с оценщиком основы до 0,1 п.п. (2116 / 1371 / 362).

**Вывод — отвергнуто.**
1. **Главная причина — залог.** В схеме весь ежедневный взнос уходит в монету, USDC в резерве появляется только из продаж. Хедж вместо продажи
   оставляет счёт перпов без USDC; по правилам Hyperliquid спот не залог, и шорт ликвидируется при первом же росте (180 тыс. ликвидаций).
   Чтобы хедж держал, часть продажи всё равно нужно делать (залог), и даже залог 3× номинала не спасает на альтах: продажи у нас как раз
   в пампах, а памп альта +200…+3000% за время хеджа (до следующего сигнала покупки) съедает любой разумный залог (55–79 ликвидаций).
2. Шорт BTC вместо продажи альта безопасен (залог ≥ 1×), но базисный риск дорогой: альт после вершины падает сильнее BTC, а BTC
   в жадности растёт — доход −1,1…−2,5 (отбор 2116 → 650–1260%).
3. Фандинг действительно платит шорту: медиана +5…+19% к итогу DCA. Но выкуп всего хеджа сразу на первом сигнале покупки вместо долей
   резерва хуже на −0,37, а неограниченный риск шорта даёт хвосты −2300…−3600% (монеты ×30 во время хеджа).
4. Единственный «плюс» (+0,10…+0,12) — свой перп без закрытия на правиле «возврата» — существует только без ликвидаций или с ликвидациями;
   по обязательному правилу «ноль ликвидаций» не проходит. Продажа проще и безопаснее; хедж вместо продажи не беру.
