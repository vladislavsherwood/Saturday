# Кому подходит combo4: признаки монеты (fit_coins.js)

181 монета (отбор, экзамен, 50 случайных, 100 новых). Результат — годовой перевес combo4 над DCA (лог(1 + результат) / лет), иначе длинная история
раздувает проценты. Прогноз без заглядывания: признаки по 1-й половине истории → результат во 2-й половине.

| признак | связь со всей историей | прогноз 1-я → 2-я половина |
|---|---|---|
| бета к BTC | 0,31 | 0,29 |
| корреляция с BTC | 0,23 | 0,20 |
| длина истории | 0,47 | 0,19 |
| волатильность | 0,18 | 0,13 |
| циклов «×2 / −50%» в год | 0,27 | 0,13 |
| просадка, рост купи-и-держи, тренд, автокорреляция, асимметрия | ≤ 0,36 | ≤ 0,13 |

Главный признак — **связь монеты с рынком (корреляция с BTC)**: все сигналы стратегии рыночные (страх, доля USDT, OI BTC, разворот BTC),
и у монеты, которая живёт своей жизнью, они не совпадают с её днами и вершинами.

- Корреляция 1-й половины < 0,2: 25 монет, 2-я половина в минусе к DCA у **9** (36%). Корреляция ≥ 0,2: 156 монет, в минусе **1**.
- По всей истории: корр < 0,2 — 36 монет, в минусе 9; ≥ 0,2 — 145 монет, в минусе 1.
- Терцили корреляции 1-й половины → 2-я половина: < 0,46 — 28%/год (15% половин в минусе), 0,46–0,56 — 40%/год (0%), > 0,56 — 41%/год (2%).
- Молодые монеты (< 600 дней) слабее: 31%/год против 42%/год у истории > 1057 дней (часть правил ждёт длинной истории, отложенная паника — с 540 дней).
- Худшие монеты: DHN, YOUC, XNC, ARIA, TA, JELLYJELLY, GROW, LBT — корреляция 0,03–0,14. Исключение WFI (0,34): почти без просадок, медленный рост.
- Волатильность сама по себе почти не важна (лучше средняя, у самой высокой больше половин в минусе — 13%).

## Что делать с «красными» монетами (fit_test.js)
Выключать стратегию хуже: corr180 < 0,1 / 0,2 / 0,3 → обычный DCA — доход −0,11 / −0,14 / −0,24, на 100 новых 503 → 356 / 257 / 160%;
запрет покупок из резерва — −0,27…−0,36. (Вариант «доли ×0,5» в скрипте посчитан с ошибкой для продаж — не использовать.)
Вывод: светофор — предупреждение и подсказка для размера вложений в монету, а не правило стратегии.

## Корреляция × волатильность (гипотеза пользователя — подтверждена)
Прогноз (признаки 1-й половины → 2-я половина), медиана перевеса над DCA, %/год [монет, в минусе]:

| | вол < 90% | 90–150% | > 150% |
|---|---|---|---|
| корр < 0,3 | 3% [2, 0] | 20% [4, 1] | 20% [26, 8] |
| корр 0,3–0,5 | 8% [3, 0] | 32% [22, 0] | 39% [22, 0] |
| корр > 0,5 | 21% [3, 0] | 40% [87, 1] | 55% [12, 0] |

Волатильность помогает только при связи с рынком: при корр. > 0,3 перевес растёт с волатильностью, при корр. < 0,3 высокая волатильность —
это зона проигрышей (8 из 26 монет хуже DCA). Отсюда и лучший одиночный признак — бета к BTC (= корреляция × волатильность монеты / волатильность BTC).

## Светофор по бете (версия 2)
Бета 1-й половины → 2-я половина (медиана перевеса над DCA, монет хуже DCA): < 0,5 — 3%/год, 6 из 14; 0,5–0,7 — 20%/год, 1 из 9;
0,7–0,9 — 32%/год, 2 из 20; 0,9–1,1 — 35%/год, 0 из 55; 1,1–1,3 — 41%/год, 0 из 39; > 1,3 — 41%/год, 1 из 44.
Пороги: ≥ 0,9 — 🟢, 0,5–0,9 — 🟡, < 0,5 — 🔴.
