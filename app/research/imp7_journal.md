# Агент улучшения №7 (imp7): режим рынка

Основа — `app/found/combo-best.json` (F + C1.25 + C6; `combo2-best.json` на старте нет): отбор 17 — 2116%, экзамен 14 — 1371%, 50 случайных — 362%
(быстрый оценщик воспроизводит точно). Направление: определить режим рынка простыми признаками BTC и проверить, стоит ли в разных режимах
менять **размеры существующих** продаж и покупок (новых сигналов не добавлять).

**Инструменты.** `app/imp7_sim.js` — поверх `combo_sim.js`: признаки режима по полному ряду BTC (страница отбора, с 2015-04; максимум 2013 г.
учтён): `rb200` = BTC/средняя 200 дн., `rw50` = BTC/средняя 350 дн. (50 недель), `rath` = % ниже максимума, `rdays` = дней с максимума,
`rlowd` = дней с годового минимума, `rup` = % над годовым минимумом, `rsl` = наклон средней 200 за 30 дней, %; `scaleK` — копия правила
с долей ×k в дни режима (как `scale` агента 4C, но по виду правила: страх/тихая вершина/фандинг/памп; паника/дно/разворот/возврат);
**оценка по циклам** — каждая монета режется по датам окна 2018-01…2019-12, 2020-01…2022-12, 2023-01…2026-11 (индикаторы посчитаны по всей
истории, резерв с нуля в начале окна, окно ≥ 270 дней; монет в окнах 22 / 55 / 81 из отбора, экзамена и 50 случайных); по каждому циклу —
Σ лог-отношений итога к основе и монет лучше/хуже.

**Режимы (заданы заранее, до расчётов).** БЫК — BTC выше средней 200 и < 20% от максимума; МЕДВЕДЬ — ниже средней 200 и средняя 200 падает;
ВОССТ (ранний восстановительный рост) — выше средней 200, но ≥ 40% ниже максимума; БОК — остальное (коррекции бычьего рынка, переходы).
По месяцам: БЫК — 2017, конец 2020 – 2021-05, 2021-10…11, 2024-03 … 2025-10; МЕДВЕДЬ — 2018-06 … 2019-03, 2020-03…04, 2022, 2026-01…08;
ВОССТ — 2016, 2019-04…09, 2020-05…10, 2023-01…2024-01, 2026-09…11 (сейчас — на границе ВОССТ/БОК: rb200 1,02, 40% ниже максимума).
Важно: в окне 2018–19 нет ни одного дня БЫКА (BTC не подходил к максимуму ближе 42%), поэтому для БЫКА доступны только два цикла.

**Критерий принятия (заранее).** Доход к основе (сумма лог-медиан трёх групп) > +0,03, строгая проверка ✔, одинаковый знак по всем циклам,
где правило вообще срабатывает (и срабатывание хотя бы в двух), соседние множители и соседние пороги режима того же знака (плато),
и эффект не должен повторяться тем же множителем без условия режима (иначе дело в размере, а не в режиме).

## Круг 1. Разбор сделок основы по режимам

**Гипотеза (заранее).** Сделки одного вида в разных режимах ведут себя по-разному и одинаково по циклам: продажи на страхе в ВОССТ — ранние
(монета через 180 дней выше), покупки паники в молодом МЕДВЕДЕ — ранние, в ВОССТ — лучше среднего. Скрипт `app/imp7_loop1.js`.

**Цифры** (монета через 90 / 180 дней после сделки, взвешено деньгами, %; для покупок — цена выше будущего 90-дн. минимума, %;
циклы 2018–19 | 2020–22 | 2023–26; для продаж «−» = продали верно):

| вид / режим | 2018–19 | 2020–22 | 2023–26 |
|---|---|---|---|
| страх / МЕДВЕДЬ (16–35% продаж) | −21 / −49 | −21 / −31 | −21 / −13 |
| страх / БОК | −50 / −62 | −16 / −50 | **+3 / +21** |
| страх / ВОССТ | −34 / −42 | **+28 / +154** (3% продаж) | −13 / −15 |
| страх / БЫК | — | −48 / −62 | 0 / −23 |
| тихая вершина / БЫК | −75 / −80 | −25 / −31 | −29 / −36 |
| фандинг / БЫК | — | −33 / −37 | −33 / −35 |
| паника / МЕДВЕДЬ | +33 / +51, над мин. 15% | +17 / +18, 25% | +1 / +5, 33% |
| паника / ВОССТ | −32 / +12, 57% | +68 / +315, 6% | −11 / +30, 18% |
| паника / БЫК | — | (27 сделок) | −5 / −30, 41% |
| разворот / МЕДВЕДЬ | −35 / −69 | −62 / −66 | — |
| разворот / ВОССТ | −28 / −59 | −33 / −16 | −12 / −28 |

**Вывод.** Гипотеза в исходном виде не подтверждена: продажи на страхе верны почти во всех режимах и циклах (исключения — БОК 2023–26 и ВОССТ
2020–22, разного знака по циклам), покупки паники в МЕДВЕДЕ дают плюс во всех трёх циклах, а в ВОССТ — разного знака. Единственная картина
одного знака по двум циклам — **разворот (возврат всего резерва при BTC +20% за 30 дней) внутри МЕДВЕДЯ** покупает перед −66…−69%
(медвежьи ралли 2018, 2022). Прямой смысл сделки по будущей цене обманчив (проданное возвращается на панике, а не через 180 дней), поэтому
решение — только по полной симуляции (круги 2–3).

## Круг 2. Размер продаж по режиму

**Гипотеза (заранее).** По кругу 1: в МЕДВЕДЕ продажи на страхе крупнее (×1,25/×1,5), в БЫКЕ и ВОССТ — меньше (×0,5/×0,75). Сетка: 4 режима ×
{все продажи, страх, тихая вершина, фандинг} × k 0,5/0,75/1,25/1,5 = 64 варианта + контроль «тот же k без режима». Скрипты `app/imp7_loop2.js`,
`app/imp7_ctl.js`.

**Цифры** (доход к основе; строгая; Σлог по циклам 2018–19 / 2020–22 / 2023–26, монет лучше/хуже):

| вариант | доход | строгая | циклы |
|---|---|---|---|
| БЫК: все продажи ×0,5 / ×1,5 | −0,55 / +0,06 | ✘ | 0 / **+1,46 / −9,60** ; 0 / **−1,94 / +5,19** — знак меняется по циклам |
| БЫК: фандинг ×0,5 / ×1,5 | −0,03 / −0,07 | ✔ / ✘ | 2020–22 за меньше, 2023–26 за больше — тоже меняется |
| БЫК: тихая вершина ×1,25 / ×1,5 | +0,083 / +0,143 | ✘ (XMR, экзамен) | 0 / +0,04…+0,09 / +1,4…+2,5 |
| контроль: тихая вершина ×1,5 всегда | **+0,143** (то же) | ✘ | то же — дело в размере, а не в режиме |
| БЫК: страх ×1,25 | +0,029 | ✘ | 0 / +0,10 / +1,11 |
| контроль: страх ×1,25 всегда | **+0,110** | ✘ | 0 / +0,82 / +1,97 — без режима лучше |
| МЕДВЕДЬ: страх ×0,5 / ×0,75 | −0,21 / −0,08 | ✘ | −−− |

**Вывод.** Гипотеза отвергнута. Уменьшать продажи нельзя ни в одном режиме (БЫК, ВОССТ, МЕДВЕДЬ, БОК — минус во всех вариантах ×0,5/×0,75),
а увеличивать — выгодно так же или больше **без** условия режима (тихая вершина ×1,5 в БЫКЕ = ×1,5 всегда, потому что тихие вершины и так бывают
только в БЫКЕ; страх ×1,25 всегда +0,11 против +0,03 в БЫКЕ и +0,01 в МЕДВЕДЕ). Размер продаж в БЫКЕ дал разный знак в 2020–22 и 2023–26 —
ровно та подгонка, от которой предупреждали. Единственный вариант с одинаковым знаком по трём циклам (МЕДВЕДЬ: страх ×1,25) не проходит
строгую проверку и почти не даёт дохода на полной истории.

## Круг 3. Размер покупок по режиму

**Гипотеза (заранее).** По кругу 1: в МЕДВЕДЕ покупки паники крупнее (резерв уходит на дно, где паника даёт плюс во всех циклах), а возврат
всего резерва на развороте — меньше (медвежьи ралли); в ВОССТ покупки крупнее; в БЫКЕ покупки паники меньше (коррекции у максимума покупаются
на 41% выше будущего минимума). Сетка: 4 режима × {все покупки, паника, дно (капитуляция + после выноса + OI), разворот} × k 0/0,5/0,75/1,5/2 = 80 вариантов
(для разворота ×1,5/×2 ничего не меняют — он уже возвращает весь резерв). Скрипт `app/imp7_loop2.js buy`.

**Цифры** (доход; строгая; Σлог по циклам 2018–19 / 2020–22 / 2023–26 (лучше/хуже)):

| вариант | доход | строгая | циклы |
|---|---|---|---|
| БЫК: паника ×0,5 / ×2 | −0,029 / +0,039 | ✘ (экзамен) | только 2023–26: −0,72 / +0,72 |
| БЫК: все покупки ×2 | +0,087 | ✘ | 0 / **−0,57 / +0,72** |
| МЕДВЕДЬ: паника ×1,5 / ×2 | −0,05 / −0,10 | ✘ | 0 / −0,17 / −1,44 |
| МЕДВЕДЬ: паника ×0,5 / ×0,75 | −0,057 / −0,034 | ✘ (худшая монета отбора) | 0 / +0,07 / **+2,59 (68/8)** — по окнам лучше, на всей истории хуже |
| МЕДВЕДЬ: дно ×0,5 / ×1,5 | −0,085 / −0,046 | ✘ | −+0 / +−0 |
| **МЕДВЕДЬ: разворот ×0 / ×0,5 / ×0,75** | **+0,073 / +0,033 / +0,017** | **✔ / ✔ / ✔** | **+0,27 (14/1) / +3,14 (44/9) / нет событий**; ×0,5: +0,01 / +0,75 (41/8); ×0,75: 0 / +0,15 |
| ВОССТ: паника ×0,5 / ×1,5 | −0,05 / +0,007 | ✘ | +−− / −+− |

**Вывод.** Для паники и дна — отвергнуто: знак по циклам меняется (ВОССТ, БЫК, БОК), а в МЕДВЕДЕ полная история и окна циклов спорят
(меньше паники в МЕДВЕДЕ лучше внутри окон 2020–22 и 2023–26, где резерв стартует с нуля, но хуже на всей истории, где он копится годами).
Единственный кандидат, проходящий все пункты, кроме третьего цикла, — **«в МЕДВЕДЕ разворот не возвращает весь резерв»** (×0 — только взнос):
+0,073, строгая ✔, монотонно по k (×0,75 → ×0,5 → ×0 растёт), противоположный контроль (разворот меньше всегда −0,14, в ВОССТ −0,26) —
значит, дело именно в режиме. Это близко к фильтру медвежьего ралли агента 2 (btc200 > 1: +0,05, отвергнут им как не лечащий обрыв порога 20%),
но здесь — как правка размера с условием наклона средней. Слабость: в 2023–26 МЕДВЕДЬ (2026) ни разу не дал разворота +20% (ралли апреля 2026
остановилось на +18,6%), т. е. проверка по циклам — только 2018–19 и 2020–22. Плато по порогам режима и разбор событий — круг 4.

## Круг 4. Плато кандидата «в МЕДВЕДЕ разворот меньше» и разбор событий

**Гипотеза (заранее).** Если фильтр медвежьего ралли — настоящее свойство режима, то (а) доход держится при соседних порогах режима (rb200 < 0,95…1,05,
наклон < −2…+2, 50-недельная средняя, глубина/возраст просадки), (б) фильтр помогает при любом пороге самого разворота (17…25%, у агента 2 там
обрыв), (в) его выигрыш собран из нескольких событий одного знака, а не из одного. Скрипт `app/imp7_loop4.js`.

**Цифры (б)** — тот же фильтр (rb200 < 1, наклон < 0, ×0) к основе с тем же порогом разворота: 17% +0,110 ✘ (половина TON −4,79 против −4,75),

**Цифры (в)** — все развороты BTC (первый день серии +20% за 30 дней) внутри МЕДВЕДЯ (rb200 < 1 и наклон < 0): **2018-07-22** ($7418, через 90/180 дн −13/−51%),

**Вывод.** Частично. (б) подтверждено: фильтр помогает при любом пороге разворота. Но (а) и (в) показывают, что это не плато, а **два-три события**:
весь выигрыш ×0 дают ралли 2022-03 и 2020-01 (rb200 0,97–0,98: при rb200 < 0,95 эффект ноль, т. к. выигрыш 2018-07 и 2022-07 съедает упущенный

на тех же пяти событиях, а в 2023–26 событий нет вовсе (ралли апреля 2026 остановилось на +18,6%). Беру ×0,5 (rb200 < 1, наклон < 0) в финальную
проверку как осторожного кандидата; принимать — только если 100 новых и маржа на пяти портфелях не хуже основы.

**Вывод.** Гипотеза подтверждена в узком смысле: кандидат проходит строгую проверку на обеих основах, стенд и 100 новых подтверждают (лучше на 37, хуже на 10,

## Итог

| круг | гипотеза | результат |
|---|---|---|
| 1 | сделки одного вида в разных режимах ведут себя по-разному и одинаково по циклам | почти везде нет; одного знака по двум циклам — только разворот внутри МЕДВЕДЯ (медвежьи ралли −66…−69% через 180 дн) |
| 2 | продажи в МЕДВЕДЕ крупнее, в БЫКЕ/ВОССТ меньше | отвергнута: уменьшать продажи вредно в любом режиме; увеличивать — так же или лучше без режима (тихая вершина ×1,5 всегда +0,14, страх ×1,25 всегда +0,11); в БЫКЕ знак меняется между 2020–22 и 2023–26 |
| 3 | покупки паники в МЕДВЕДЕ крупнее, разворот меньше, в ВОССТ крупнее, в БЫКЕ меньше | для паники и дна — отвергнута (знак по циклам меняется, полная история и окна спорят); единственный кандидат — разворот в МЕДВЕДЕ ×0…×0,5 (+0,03…+0,07, ✔) |
| 4 | фильтр медвежьего ралли — плато по порогам режима | ×0 — пик (весь выигрыш от ралли 2022-03 и 2020-01, при rb200 < 1,1 минус из-за 2023-01); ×0,5 — узкое плато (rb200 < 1…1,05, наклон < 0…+2: +0,025…+0,040 ✔); помогает при любом пороге разворота 17…25% |
| 5 | стенд, 100 новых, маржа, combo2 | ✔: 2164 / 1377 / 366 / 345% (37/10 на 100 новых), +0,059 поверх combo2, 0 ликвидаций на пяти портфелях, медианы портфелей без изменений |

**Главный вывод о режимах.** Простые признаки режима (BTC к средней 200 / 50 недель, просадка от максимума, дни с максимума, наклон средней) не дают устойчивой
причины менять размеры продаж и покупок: почти все эффекты либо меняют знак между циклами (особенно БЫК 2020–22 против 2023–26), либо повторяются тем же
множителем без режима (значит, дело в размере). Режимов мало: в окне 2018–19 нет ни дня БЫКА, в 2023–26 нет ни одного разворота в МЕДВЕДЕ. Единственное,
что прошло всё, — половинный возврат резерва на развороте в медвежьем режиме, и то как маленькая осторожная добавка.

**Можно объединять:** правка касается только правил разворота (`btcr30 > 20`) и не пересекается с правками продаж (C, сегменты combo2, A4/шорт в марже) —
поверх combo2 даёт +0,059 и строгую ✔. Для приложения нужны два новых индикатора BTC: `rb200` (по полной истории BTC, не по дням страницы) и `rsl`.

**Ограничения.** Пять событий (2018-07, 2020-01, 2020-04, 2022-03, 2022-07), из них апрель 2020 — лучшая покупка, которую правка уменьшает; в 2023–26 правило
ни разу не срабатывало (ралли апреля 2026 остановилось на +18,6%); медианы портфелей не меняются, P9 по стартам 2018–20 чуть хуже (−1…−2%). Отбор/экзамен/50 случайных
давно использованы для подбора; оценка по циклам стартует резерв с нуля и для паники в МЕДВЕДЕ спорит с полной историей.
