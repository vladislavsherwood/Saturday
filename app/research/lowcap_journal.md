## Круг 0. Выборка, данные, основа на лоукапах и где она ошибается

**Выборка (зафиксирована до расчётов).** Кандидаты: все перпы Hyperliquid, включая снятые (235), с датой появления на CMC ≥ 2021, плюс
монеты CMC с тегами «memes»/«ai-agents» среди первых 1200 (появились 2021 … 2025-11) и список пользователя — 239 монет.
Признак «лоукап» — **по данным**, не по названию: медианная капитализация CMC за всю историю ≤ $1 млрд, максимум ≥ $30 млн, медианный
объём ≥ $2 млн в день, история ≥ 420 дней (год после 20 дней разогрева, как у стенда), капитализация есть хотя бы у половины дней, не стейблкоин/обёртка.
Прошли **157 монет** (не прошли: крупные — HYPE, SUI, TAO, PEPE, ENA, WLD, ARB, TRUMP, OP, KAS…; молодые < 420 дн — XPL, 2Z, 0G, KITE, MET…;
малый объём — TIBBIR ($1,9 млн), SNEK, GOHOME, ANDY, BERT…). Из списка пользователя в выборке: USELESS, PENGU, FARTCOIN, SPX, MOODENG, POPCAT,
GOAT, VIRTUAL, ZEREBRO, ACT, PNUT, TURBO, MEW, BRETT, GIGA, MOG, JELLYJELLY; нет TIBBIR (объём) и AI16Z (CMC перенёс историю на новый
номер ELIZAOS с 2025-11 — молодой).
**Разбиение по монетам** (случайно, seed 20261114): отбор **78**, проверка **79**. **Время:** до / после 2025-06-01 (по дню решения).

**Где основа ошибается на лоукапах** (`lowcap_loop0.js`; отбор лоукапов против отбора+экзамена+50 случайных стенда; доходность монеты после сделки,
взвешенная деньгами; «ошибка» — продажа, после которой монета выросла > ×2 за 120 дн, или покупка, после которой упала > 50%):

| сделки | лоукапы: денег / через 30, 90, 180 дн / ошибок | стенд |
|---|---|---|
| покупка на панике | 43% / −1, +1, −11% / **43%** | 35% / +1, +6, +8% / 14% |
| — до 2025-06 | 41% / +25, +52, +51% / 2% | |
| — **после 2025-06** | 44% / **−11, −20, −47%** / **60%** | |
| покупка на развороте BTC | 1,9% / +39, +52, +31% / 20% | 6,7% / +20, −3, −22% / 23% |
| возврат после тихой вершины | 0,8% / 0, −5, −8% / 50% | 0,4% / +67, +26, −3% / 2% |
| продажа на страхе / сильном страхе | 43% / −10…−20, −16…−22, −18…−37% / 10–11% | 42% / −6…−9, −7…+5, −15…−4% / 10–13% |
| продажа на тихой вершине | 5,9% / −21, −50, −32% / 9% | 5% / −18, −44, −42% / 1% |
| продажа на широкой тихой вершине | 3,4% / −1, +41, −21% / 21% | 3% / −5, +32, +1% / 51% |
| продажа пампа (F) | 0,9% / −21, +70, +91% / 6% | 0,2% |

Метрики (отбор лоукапов / стенд): покупки резерва выше 90-дн. будущего минимума на **64% / 36%**, в зоне +15% от дна цикла **6% / 16%** денег;
пропущено крупных вершин **22% / 7%**; продажи на 68 / 71% от максимума ±90 дней.
Паника у вершины монеты (ddm90 < 35, форма P35 агента «мемы»): у лоукапов это лишь 31% денег паники (через 90 дн −6%), остальные 69% —
монета уже ниже своего 90-дн. максимума на 35%+, но всё равно падает дальше. У стенда наоборот: 63% денег паники у вершины, и это лучшие покупки (+10%).

**Примеры.** Ловля ножа (2025–26): SAGA 2026-01-16 (дальше −73%), LAYER 2026-01-08 (−56%), DEGEN 2025-11-13 (−60%), ACE 2024-10-06 (−52%),
BITCOIN 2024-10-11 (−65%), NPC 2023-09-11 (−51%); fng < 10 в феврале 2026: ACE, ARC, DOOD, PAAL, SAGA −53…−67%. Ранние продажи на тихой вершине в начале пампа:
ACN 2023-12 (дальше ×26), MOG 2024-01 (×21), PAAL 2024-01 (×5,6), BITCOIN 2024-01 (×3,2). Пропущенные вершины — пампы при BTC у максимума (правило пампа молчит).

**Вывод.** Главная слабость основы на лоукапах — **резерв уходит на рыночную панику в медвежьем рынке альтов (2025–26), когда лоукап
продолжает сливаться** (60% денег паники — «ошибки», через 180 дней −47%); до 2025-06 те же покупки — лучшие (+51%). Вторая — ранние продажи
на (широкой) тихой вершине в начале пампа лоукапа (как у мемов; агент «мемы» показал, что это частично иллюзия). Третья — 22% пропущенных
вершин. Продажи на страхе у лоукапов, наоборот, работают лучше, чем у стенда. Отсюда план: искать в объёме/обороте/деривативах **признак
«лоукап ещё сливается» против «продавцы кончились»** — без жёсткой защиты по цене (агенты 3/4C показали, что она вредна у крупных монет).
